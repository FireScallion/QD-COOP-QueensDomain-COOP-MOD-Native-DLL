Current Steam build26496428: GameEngine vtable RVA0x3E49C38, Tick slot86,
cellRVA0x3E49EE8, original targetRVA0x28C4D80; Win64 void(this,float,bool).
Observed through the actual GameEngine object, UE4SS log and game disassembly.
The bridge verifies the running executable SHA256 and expected cell, pins both
callback and bridge DLLs, uses an interlocked compare/exchange under temporary
page write permission, restores page protection, and always invokes the original
Tick with all three arguments. No instruction trampoline or UE4SS registration.
Installation is serialized/idempotent; a conflicting callback or cell is rejected.
Unloading a successfully installed callback is unsupported.

Build-EnemyM1 now builds both DLLs with GCC. The retained VcVars64 parameter is
unused compatibility input; MSVC is no longer required. Old UE4SS bridge source
is historical and not built. The core still requires its cold Lua bootstrap.
