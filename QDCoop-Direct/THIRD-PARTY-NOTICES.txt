Queen's Domain
QD COOP uses game class and asset references, bone names, and rig calibration.
The player package contains cooked mod assets that include game-derived
material. Confirm redistribution permission for those assets before posting
the player archive publicly. The source package omits the cooked Paks and raw
game assets and preserves the code and reference metadata used by the mod.

Skin appearances
Soldier body, helmets and face textures originate from Queen's Domain.
The mod rebinds their geometry to the existing prince skeleton and renders
menu portraits from these meshes. These are game-derived assets, not wholly
new original artwork. The source archive includes the binding/authoring code
and bone-name mapping; extracted meshes/textures and cooked assets are omitted.
